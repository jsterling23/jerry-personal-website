
# Jerry Personal Website

A custom WordPress website I'm developing to showcase my interests and projects in cybersecurity, software development, media production, and disc golf.

## Project Overview

This website uses a custom WordPress theme built with PHP, HTML, and CSS. WordPress manages the content, while the theme controls the layout, appearance, and functionality.

The website is being developed locally and will eventually be deployed to a DigitalOcean Ubuntu server.

## Technologies

- WordPress
- PHP
- HTML5
- CSS3
- MySQL
- Git and GitHub
- Ubuntu / Apache (production hosting)

## Website Sections

- **Technology & Cybersecurity:** Programming, security labs, and technical projects.
- **Media Production:** Photography, video production, and creative work.
- **Disc Bandit:** Disc golf, training, tournaments, and related content.

## Features Implemented

- Custom WordPress theme
- Responsive homepage
- Shared header, footer, and navigation
- Dynamic project listings using WP_Query
- Individual project pages
- Custom project metadata
- GitHub repository links

## Development

Development takes place locally using Local and Visual Studio Code.

The repository contains the custom theme rather than the entire WordPress installation.

## Status

In active development.
